# 大屯地熱數據系統

地熱開發角色扮演桌遊的輔助網頁，以陽明山（大屯火山群）地熱開發的真實事件與公開數據為案例。玩家拿紙牌進行遊戲，抽到事件卡時，用手機掃 QR code 查看這張卡的數據、來源與可信度，以及自己的角色看到的現況。

- 系統首頁：`index.html`（分頁：抽卡現場、我的身分、事件卡 A–P、判斷卡、決策規則）
- 連線與事件卡 QR code：`qr.html`

## 資料來源與使用限制

- 內容依據《陽明山（大屯火山群）地熱開發決策系統 — 參考資料庫》v1.1，資料蒐集截止 2026-11-08。
- 每筆數據都標有來源代碼（S01…）與可信度（官方、學術、媒體、業者）；完整清單在「決策規則」分頁最下方。標「未公開」的項目代表查不到公開資料。
- 事件卡 F 為他區（宜蘭員山）對照案例，E、K 引用他區（花蓮紅葉）經驗，P 為情境推演。
- 「決策規則」分頁的角色權重與預設分數是示範用假設值，不是任何真實案場的評估結果。
- 法規門檻（噪音、環評、躉購費率等）會修正，實際標準以全國法規資料庫與主管機關最新公告為準。
- 角色是虛構人物，台詞不代表任何真實個人或團體的立場。本系統為教學用，不構成法律、投資或工程建議。
